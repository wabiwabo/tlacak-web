03 / Round 3 · Research-backed

grounded in real refs · awwwards / game UI / enterprise / competitors

Four directions distilled from real research across web design 2026, gaming HUDs, adjacent enterprise tools, and the fleet tracking competitive baseline. Each is grounded in concrete inspirations rather than pure ideation.

01 / CHART TABLE
01 / 04 · MAP-AS-CANVAS

Chart Table

Map = whole canvas, no sidebars. Custom dark Jakarta basemap (no Google Maps default — first fleet app to dare). Data lives ON markers (diegetic). Tracing-paper overlays, multiplayer ghost cursors. Refs: Felt, Foursquare Studio, Dead Space remake, Star Citizen.

No Chrome Custom Map Diegetic Multiplayer

02 / RISO OPS
02 / 04 · PRINT ROOM

Riso Ops

180° from Cyber Ops. Warm cream paper, two-color riso (teal+vermilion), printed dispatch sheet layout, woodblock-engraved map, ink-stamp elements, dossier as typed form. Only fleet app competing for trustworthy not futuristic. Refs: Charlotte Rohde, It's Nice That 2026.

03 / LIVING PHYSICS
03 / 04 · DEPTH = DATA

Living Physics

Cyber Ops evolution. 5 elevation levels with semantic meaning (recessed=parked, protruding=incident). Bottom strip = physical mixing board with different tile heights. Read operational state from a 5m distance, no text needed. Refs: Sentry SCRAPS 2025, visionOS 26 spatial widgets.

04 / ELEVATOR
04 / 04 · TRIPTYCH MODES

Abstraction Elevator

Three genuinely different layouts, not filter states. EXECUTIVE (editorial cream + serif), DISPATCH (dark exception queue, silence-as-design), VEHICLE (forensic 24h trace). One keystroke switches altitude. Refs: Cursor 3, Honeycomb Canvas, Grafana 12.
